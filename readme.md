# D1 Skincare Landing Page

## Run Locally

This project is a static site (no build step required). You can run it in any of the following ways:

### Option 1: Open directly

1. Open `index.html` in your browser.

### Option 2: Use a simple local server (recommended)

This avoids any browser restrictions on local files.

1. From the project root, run:

```bash
npx http-server -p 8080
```

2. Open the site at `http://localhost:8080`.

Then open the URL shown in your terminal.

## For development purposes run the command to watch for changes and auto compile.

1. From the project root, run:

```bash
npx sass --watch src/scss/main.scss dist/styles.css
```
